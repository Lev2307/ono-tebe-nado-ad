# Оно тебе надо

Учебный проект по дисциплине второго курса «Фронтенд-разработка» — статичная веб-страница аукциона, свёрстанная по макету из Figma (максимальная ширина 1100 px, без адаптива).

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, псевдоэлементы)
- Локально подключённые шрифты Raleway (@font-face)

## Структура проекта

```
ItReallyNeedsU/
├── index.html        # разметка страницы
├── styles/
│   ├── style.css     # основные стили
│   ├── global.css    # сброс и глобальные правила
│   └── fonts.css     # подключение шрифтов
├── fonts/            # Raleway Regular и Bold
└── images/           # изображения (обложка, лоты, логотипы, иконки)
```

## Запуск

Откройте `index.html` в браузере — сборка не требуется.

## Секции страницы

- **Шапка** — меню, логотип, контакты
- **Обложка** — заголовок «Оно тебе надо» и кнопка «Сделать ставку»
- **Лоты** — три карточки с затемнением поверх фоновых изображений
- **Об аукционе** — текстовый блок с логотипом
- **Футер** — контакты, навигация, ссылки на соцсети
